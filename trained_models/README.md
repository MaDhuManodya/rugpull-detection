# Trained Models

This directory stores trained model weights.

## File Naming Convention
```
{model_name}_{experiment_name}_{timestamp}.pt
```

Examples:
- `gatv2_tgn_experiment_01_20260801.pt`
- `xgboost_baseline_20260801.pkl`

## Gitignore
Model files (`.pt`, `.pth`, `.pkl`) are excluded from git.
Only this README is tracked.
